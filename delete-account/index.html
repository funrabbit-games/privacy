계정 및 데이터 삭제

뽑뽑 : 인형뽑기 크레인 게임 · 개발사 FunRabbit

한국어 English

뽑뽑 : 인형뽑기 크레인 게임(이하 "본 게임")의 계정과 계정에 저장된 데이터를 삭제하는 방법을 안내합니다.

방법 1. 게임 안에서 삭제 (즉시)

  1. 게임을 실행하고 로그인합니다.
  2. 설정을 엽니다.
  3. 계정 삭제를 누르고, 안내에 따라 두 번 확인합니다.
  4. 삭제가 끝나면 게임이 처음 상태로 다시 시작됩니다.

방법 2. 이메일로 요청 (게임을 삭제했거나 실행할 수 없는 경우)

아래 주소로 이메일을 보내 주세요.

  • 받는 사람: funrabbit.support@gmail.com
  • 제목: 뽑뽑 계정 삭제 요청
  • 본문: 게임에 로그인할 때 사용한 Google 계정 이메일 주소

요청을 받으면 본인 확인 후 30일 이내에 삭제하고, 처리 결과를 이메일로 알려 드립니다.

게스트로만 플레이한 경우 계정이 기기에만 연결되어 있어 이메일로 본인을 확인할 수 없습니다. 게임 안의 설정 → 계정 삭제를 이용해 주세요.
